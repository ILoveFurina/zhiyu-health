# 89 - RAG 知识文档上传与切分闭环

**What to build:** B 端"知识文档"运营页打通端到端闭环--管理员上传 Markdown/纯文本文档（选标准科室）-> server-java 异步解析切分 -> 调 server-py 批量 embedding -> 写 `knowledge_chunks` -> 文档状态 `PROCESSING -> READY`，新 chunk 立即可被 C 端导诊 RAG 检索命中。admin 可查看文档列表（含系统预置 50 条 seed + 上传文档）、状态轮询、查看失败原因并重试、归档文档（连带删 chunk，检索 SQL 零改动）。现有 50 条 seed 知识纳入文档模型统一管理（只读）。设计依据 ADR-0036。

**Blocked by:** 无（ADR-0036 已定稿；MinIO 写路径已由票 54 落地；`knowledge_chunks` 表已存在）

**Status:** done

- [x] schema：`schema.sql` 新增 `knowledge_documents` 表（`id, file_name, content_type, byte_size, object_key, source(SEED/UPLOAD), status(PROCESSING/READY/FAILED/ARCHIVED), department, uploader_staff_id, error_code, error_message, processing_started_at, chunk_count, created_at, updated_at`）；`knowledge_chunks` 加 `document_id BIGINT` 外键列（`ADD COLUMN IF NOT EXISTS`，可空以兼容存量）；`seed.sql` 新增一条 `source=SEED` 系统预置文档行（status 永远 READY），50 条 seed chunk 回填 `document_id` 指向该行；幂等（`CREATE TABLE IF NOT EXISTS` / `ON CONFLICT DO NOTHING`）
- [x] contracts：新增 `contracts/knowledge-documents.json`（`document_status`/`document_source` 枚举、`orphan_timeout_seconds: 600`、`embedding_endpoint` 含 path/max_texts/batch_size/timeout/error_codes、`embedding_input_format: "{title}。{content}"`、`chunking.chunk_size: 500`/`chunk_overlap: 50`、`upload.allowed_types: [text/plain, text/markdown]`/`allowed_extensions: [.txt,.md]`/`max_file_bytes: 2097152`/`max_files: 1`、`title_format: "{document_title} - 第{n}段"`）；`ContractsTest` 同步断言
- [x] server-py：新增 `POST /api/agent/knowledge/embeddings`（router prefix `/agent/knowledge`，`AgentCallbackAuth` 共享密钥）；请求体 `EmbedRequest{texts: list[EmbedTextItem{title, content}]}`（`ConfigDict(extra="forbid")`，1-50 项，title ≤200 content ≤8000）；对每项拼 `f"{title}。{content}"`（与 `seed_embeddings.py` 一致）分批 10 调 `aembed_documents`；响应 `EmbedResponse{vectors: list[list[float]]}`；维度校验 == `settings.knowledge_embedding_dimension`(2048) 不匹配 502；错误码 `KNOWLEDGE_EMBEDDING_INVALID`(422)/`EMBEDDING_MODEL_TIMEOUT`(504)/`EMBEDDING_MODEL_FAILED`(502)；复用 `build_embedding_model`
- [x] server-java agentclient：`AgentClient` 新增 `embedKnowledgeTexts(List<EmbedTextItem>) -> List<float[]>`，走既有 WebClient（header 自动带），`.block(60s)`；新增 `KnowledgeEmbeddingAgentApi`（与 `VisionAgentApi`/`VoiceAgentApi` 同构，error mapping 提取 `detail.code` 白名单后抛 `ApiException`）
