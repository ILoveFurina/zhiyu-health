# 96 - 首页未读消息提醒与服药打卡待办

**What to build:** 针对 P2 反馈「首页无未读消息提醒，通知中心藏在我的中心最底部」，经 grilling 共识（方案 A：通用未读角标，演示可发现性优先；不引入服务端已读字段）：

1. 首页问候头右上角加消息中心入口（mail 图标 + 未读数字角标）。未读数 = `/c/messages` 返回列表中不在本机已读集合的条数，与消息中心页共用同一份本机 storage 口径；仅 `onShow` 拉取（不进 10s 轮询），点击直达消息中心，已读返回后数字自动消失。
2. 服药打卡 PENDING 提醒进入首页待办横卡：每笔提醒一张卡、排在待办末尾，卡上内联「已服用」按钮就地打卡（对齐 `payTodo` 的 catchTap 模式），成功 toast 连续天数并就地摘卡；消息中心原有打卡区不动。

零后端改动、不动 schema；未读数与打卡均不实时轮询。

**Blocked by:** 22 — 服药打卡；60 - 处方闭环串联与创新点补齐（站内消息通道）；72 - 首页信息架构
