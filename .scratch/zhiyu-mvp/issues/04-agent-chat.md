# 04 — Agent 对话主干（含红线安全门、开场提示词与推理档位）

**What to build:** 小程序聊天页与 Agent 多轮对话打通：LangGraph 循环接入 doubao-seed-2.1-turbo（ADR-0004/0005），会话与消息持久化；免责声明标注由后端统一注入并由全局组件渲染在每条 AI 健康建议上；Agent 主干内置红线症状确定性规则安全门，命中后立即中断导诊并展示红色警告与 120 提示；AI 页初始展示 3 个推荐提示词（导诊/用药注意/健康管理各一，点击即发）；用户可切换推理档位（自动/快速回答/深度思考，默认自动）；随此票建立 patients 表（仅承载 C 端 mock 登录身份）与免注册 mock 登录。

**Blocked by:** 01 — 项目骨架与基础设施

**Status:** ready-for-agent

- [ ] 聊天 UI（气泡 + 输入框）与会话/消息持久化
- [ ] LangGraph Agent 循环支持多轮上下文（追问能力）
- [ ] 后端对全部 AI 产出统一注入免责声明字段，小程序全局组件无遗漏渲染
- [ ] 红线症状规则表与判断逻辑位于 service 层，规则判断先于 LLM/工具循环执行
- [ ] 命中红线症状后立即中断导诊，展示红色警告卡片并建议尽快就医或拨打 120
- [ ] 红线规则测试覆盖危险输入必触发、普通症状不误触，以及命中后不再调用导诊工具
- [ ] 3 个开场推荐提示词可点击发送
- [ ] 推理档位三档切换并由后端映射后传值：自动档按场景分配（导诊 low、解读 high），快速回答映射 low，深度思考映射 high，永不把 `auto` 直接作为 `reasoning_effort` 发送
- [ ] patients 表 + C 端 mock 登录（免注册即得患者身份，过敏史归 health_profiles 而非 patients）
- [ ] 对话消息经 SSE 推送（与后续工具调用可视化同通道）
- [ ] fake LLM 的多轮对话循环测试（上下文保持）
