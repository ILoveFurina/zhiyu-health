# 86 - 在线问诊闭环与待办追踪完善

**What to build:** 修复在线问诊/挂号链路四处闭环缺口（一张票施工，建议按下列四段顺序提交）：

1. **预问诊放弃入口视觉升级**：预问诊页与摘要确认页底部的灰色文字链接（`preconsult/index.axml:77`、`summary/index.axml:35`）升级为正式次级描边按钮（全宽、置于底部安全区上方），文案保持"放弃本次预问诊"，确认弹窗与后端 `abandon` 逻辑不动。纯 miniprogram 样式改动。
2. **问诊中闭环（患者主动结束 + 时长窗超时）**：
   - 契约 `contracts/online-consultation.json` 新增 `consultation_duration_seconds`（默认 1800），自医生接受问诊起计时。
   - server-java：患者主动结束接口（二次确认后置 `CANCELLED`，写系统消息"患者已结束问诊"）；到期惰性收敛（复用现有 expire 模式）置 `EXPIRED` 并写系统消息"问诊时间已到，本次问诊已自动结束"，正常释放每档案一条活跃问诊额度；发消息等入口同步惰性判定。
   - C 端医患交流页顶部常驻倒计时条（逐秒，最后 5 分钟变橙提示"即将结束"），到点锁输入区；新增"结束问诊"入口（二次确认文案说明结束后不可恢复）。
   - B 端问诊抽屉同步显示剩余时间，到点后状态同步锁定。
3. **线下挂号待办卡"就诊中"中间态**：首页过滤由仅 `BOOKED` 扩为 `BOOKED || IN_PROGRESS`；叫号后卡片徽标变"就诊中"、文案加"医生已叫号，请前往诊室就诊"，点击跳挂号详情；`VISITED` 后消失。
4. **处方追踪待办卡**：`PatientConsultationProgressService` 投影扩为"活跃态 + 已完成但处方未终结"；问诊 `COMPLETED` 且有处方时——`PENDING` 显示"处方审核中"、`APPROVED` 未下单显示"处方已通过，去购药 ›"（点击均跳处方详情），下单后交接给现有药品待支付卡，支付完成消失；无处方直接消失（保持现状）；`REJECTED` 显示"处方未通过，点击查看详情 ›"，同一档案发起新问诊时旧卡被新链路覆盖消失（服务端只投影每档案最近链路的未终结处方）。
