# 27 — 对话记录（会话列表、新对话、切换续聊与删除）

**What to build:** C 端用户可见的对话记录功能（参照腾讯健康问问抽屉）：聊天页抽屉展示当前患者的会话列表（按最近活跃倒序，上限 50 条，不做时间分组），支持「新对话」、点选历史会话回看并续聊、单条删除（不做批量管理模式）。会话惰性创建：点「新对话」仅重置前端聊天态，首条消息发出时后端才建会话；标题取首条用户消息截断（图片消息显示场景名如"拍皮肤"），空态显示"新对话"。冷启动 AI 页每次进入全新聊天态，历史仅从抽屉进入。删除会话只删对话数据，不影响挂号单等业务实体。术语以 CONTEXT.md「会话 / 对话记录」为准。

**Blocked by:** 31 — 票 04 拆分迁移（红线规则引擎随票迁 server-java，SSE 契约不变）

**Status:** ready-for-agent

- [ ] 会话列表接口：按患者查询，最近活跃倒序，上限 50 条，返回会话 id / 标题 / 最近活跃时间
- [ ] 会话消息查询接口：进入历史会话时全量返回该会话消息用于 UI 回放
- [ ] 惰性创建：首条消息发出时才落库会话并生成截断标题；空会话不出现在列表
- [ ] 新对话：前端重置为空聊天态，后续消息归属新会话
- [ ] 历史会话切换：加载消息后可在该会话内续聊（延续 04 票的 SSE 与多轮上下文机制）
- [ ] 单条删除接口与 UI（左滑/长按），删除仅清除会话与消息，不触碰业务实体
- [ ] 冷启动 AI 页为全新聊天态，不自动恢复上次会话
- [ ] 断流回复由后端写完落库，历史会话中可见完整内容
- [ ] 会话归属患者账号，不随健康档案切换过滤
- [ ] fake LLM 测试：惰性创建时机、标题截断、列表倒序与上限、删除后列表与消息清除、续聊上下文保持
