- 演示范围：30 张已冻结票（见 `.scratch/zhiyu-mvp/rehearsal.md` 冻结清单）

- 不在冻结范围：43（就诊指引卡）、44（情绪标注）、45（语音）、35/36（挂号收费支付）——剧本不得出现这些功能

## 演示前检查单

每遍演示前逐项确认，全部通过再开始：

- [ ] server-java 健康：`curl http://127.0.0.1:8080/api/health` 返回 `ok`，含 PG/Redis/Neo4j 三项
- [ ] server-py 健康：`curl http://127.0.0.1:8000/api/health` 返回 `ok`
- [ ] 已执行演示重置（B 端演示看板 -> 演示重置，确认短语 `DEMO_RESET_CONFIRM`），断言全绿
- [ ] B 端可访问：`http://localhost:5173`，用 `admin/admin123456` 登录成功
- [ ] 小程序开发者工具已导入 `miniprogram/`，模拟器关闭域名校验
- [ ] 火山方舟 API 可用（LLM 首 token < 10s）
- [ ] 录屏软件就绪（OBS/系统录屏），4 条视频命名与拍号对应（见录屏兜底段）

## 主线（9 拍，≤5 分钟）

以林小满就诊全流程为线索：登录 -> 红线拦截 -> 症状咨询 -> 导诊推荐 -> 挂号 -> B 端接诊 -> 开方审核 -> C 端解读 -> 收尾。

### 拍 1｜C 端 mock 登录林小满（20s）

| 项 | 内容 |
| --- | --- |
| 操作 | 小程序 AI 对话页 -> 顶部 mock 登录入口，输入「林小满」登录 |
| 话术 | "我们跟随一位带青霉素过敏史的患者林小满，体验完整的智能导诊到就诊流程" |
| 预期 | 登录成功，健康档案显示已激活（林小满本人，青霉素过敏标记可见） |
| 时长 | 20s |
| 兜底 | 登录失败 -> 切主线录屏第 1 段；健康档案未显示过敏 -> 手动进档案页确认 seed 数据 |

### 拍 2｜红线症状拦截（30s，可裁）

| 项 | 内容 |
| --- | --- |
| 操作 | 在 AI 对话页输入「我胸口很痛，还一直出冷汗」 |
| 话术 | "系统优先执行红线规则引擎，胸痛伴冷汗是急性冠脉综合征危险信号，立即中断并引导就医" |
| 预期 | 不进入 Agent 对话流，直接展示红色警告卡片，建议拨打 120 / 就近急诊，底部带免责声明 |
| 时长 | 30s |
| 兜底 | 未触发红线 -> 确认输入含"胸痛"+"冷汗"关键词；切红线录屏段 |
| 备注 | 此拍展示安全硬约束，可单独裁出作为支线，不计入主线 5 分钟也可 |

### 拍 3｜症状咨询 + 共情追问（45s）

| 项 | 内容 |
| --- | --- |
| 操作 | 点「新对话」重置，输入「最近总觉得心慌，活动后有点气短，晚上偶尔憋醒」 |
| 话术 | "非红线症状进入 Agent 导诊，Agent 会追问发作频率和诱因来收集信息" |
| 预期 | Agent 回复带免责声明，追问发作频率/持续时间/是否伴心悸；回复底部出现工具进度状态条（如"正在检索知识…"） |
| 时长 | 45s |
| 兜底 | LLM 首 token >10s -> 切对应录屏段；回复无免责声明 -> 停下检查注入逻辑 |

### 拍 4｜科室与医生推荐（40s）
