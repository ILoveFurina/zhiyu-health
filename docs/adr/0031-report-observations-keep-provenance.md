# 报告健康观测自动沉淀但保留来源与替代链

Status: accepted

多模态报告解读中的受控白名单项目由 server-java 确定性映射并自动沉淀为 `UNVERIFIED` 健康观测，使报告上传能直接形成健康档案概要；观测始终携带明确检查日期、来源报告与核验状态，AI 提取不冒充医生确认。患者确认只推进核验状态，纠错通过追加新记录并将旧记录标为 `SUPERSEDED`，排除保留终态记录；任何操作都不覆盖或删除原始来源链。

采用追加式来源模型而非直接更新，是因为报告原图按既有隐私决策即用即弃，持久化后的结构化结果和替代链必须承担可追溯职责。采用自动沉淀而非“确认后才入档”，是为了让报告解读与健康概要形成连续产品闭环；风险通过 `UNVERIFIED` 徽标、受控指标白名单、server-java 二次校验和固定免责声明约束。

一期以天为粒度，每份健康档案每个指标每天只有一个 current 槽位；重复报告不产生重复趋势点，同报告出现冲突值则不沉淀该指标。若未来需要一天内多次血压、设备实时流或医生确认，本决策的数据粒度和授权边界必须重新评估。
