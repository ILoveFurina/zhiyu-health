# C 端 Agent 不做个性化用药决策

Status: accepted（收窄 ADR-0009 与原硬规则 2 中用药禁忌的适用范围）

C 端 Agent 移除 `check_contraindication` 工具，不再结合患者健康档案决定具体药品、剂量、替代药或某位用户是否可以服用，只提供药品用途、说明书与常见注意事项等通用知识解释，并在个性化问题上引导咨询医生或药师。server-java 的确定性禁忌与相互作用检查仅保留在 B 端医生开方流程并继续阻止不安全处方；C 端红线症状规则不变。

## Consequences

- Agent 不再为了等待禁忌工具决定而缓冲模型正文，普通回答可以单阶段逐 token 展示。
- 从 Agent 工具集、跨栈工具事件映射与测试中移除禁忌工具；B 端处方安全接口、规则、契约决定值和测试继续保留。
- 通用知识解释不得伪装成个性化用药建议；该边界由 system prompt 与面向用户的咨询医生/药师提示共同表达，但不把 LLM 输出当作确定性处方结论。
