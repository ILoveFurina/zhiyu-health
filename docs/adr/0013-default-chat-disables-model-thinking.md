# 普通对话默认关闭模型思考

Status: accepted（取代 ADR-0004 中自动档 `triage → low` 的映射）

C 端推理档位继续保留快速回答、自动和深度思考，但普通对话/导诊不再默认使用 `reasoning_effort=low`：实测 low 的首正文约 5.7 秒，而关闭思考约 1.4–1.8 秒，且当前模型不支持 `thinking.type=auto`。快速回答始终关闭思考；自动档由产品按场景选择，普通对话/导诊关闭思考，报告解读等复杂任务使用 high；深度思考始终使用 high。server-java 的红线与禁忌确定性规则继续承担安全边界，不能用模型思考延迟替代规则判断。

## Consequences

- 默认聊天与快速回答在普通对话中使用相同的无思考模型配置，自动档只在复杂解读场景体现差异。
- 不使用关键词规则判断单条问题是否“简单”，避免医疗表达误分类和不可解释的延迟抖动。
- 若未来模型原生支持可靠的自动思考模式，需以真实 TTFT 与工具调用回归测试重新评估，而不是仅按参数名称切换。
