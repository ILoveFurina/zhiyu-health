# C 端改用支付宝原生小程序（替代微信原生小程序）

Status: accepted（supersedes ADR-0002）

开发中期接到外部需求，C 端载体由微信小程序全量替换为支付宝小程序，两端不并存。技术路线维持 ADR-0002 的"原生"判断：支付宝原生小程序（AXML + `my.*` API）+ antd-mini 组件库，不引入 uni-app/Taro 跨端框架。

决策时微信端仅有 1 个健康检查页与 2 处 `wx.*` 调用，登录/支付本就在 mock 边界内，迁移沉没成本极低；C 端业务功能（导诊对话、挂号、档案等）尚未开发，此后直接按支付宝 API 实现，避免先写微信版再返工。

受影响的既有决策：

- 组件库 `@vant/weapp` → antd-mini（支付宝官方，维护活跃）。
- 语音链路放弃微信同声传译插件：`my.getRecorderManager` 录音 → 火山引擎语音识别 REST → 文本进对话；TTS 播报同样用火山引擎，与火山方舟 LLM（ADR-0004）同账号体系。
- 演示仍以开发者工具模拟器为主，不上架、不审核、不要求 HTTPS 域名；登录、购药、支付维持 mock 边界不变。

考虑过的替代方案：两端并存（跨端框架重写或双端维护，两周 demo 周期内测试面翻倍，拒绝）；转换工具机翻后修补（现有代码量极小，直接重写更干净，拒绝）。
