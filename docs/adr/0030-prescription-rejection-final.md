# 处方驳回即终态，不开放改方重提

Status: accepted

电子处方与来源一对一（`prescriptions.appointment_id` UNIQUE / `uq_prescriptions_online_consultation`）。审核驳回（REJECTED）后该处方即终态：患者收驳回站内消息并被引导重新发起问诊或挂号（在线问诊单可复用原摘要重新提交），开方医生在 B 端接诊抽屉可见状态与驳回原因；既不能修改原方重新送审，也不能对同一来源再开新方——唯一约束与"开方要求问诊 IN_PROGRESS"规则均不动。

被否决的方案：

- 原方修改重提（REJECTED → PENDING 状态回转）：驳回通常发生在问诊 COMPLETED 之后，重提会让"已完成"的问诊重新挂出待审处方，在线问诊进度语义混乱，且需新增 B 端编辑入口与状态回转逻辑。
- 放开一对一、允许重开新方：唯一索引需改为部分唯一（每来源仅一张非 REJECTED），IN_PROGRESS 开方限制也要放开，改动面最大。

后果：答辩口径为"处方被驳回意味着需要重新诊疗而非修补原方"；驳回通知把支路接回主闭环，患者侧不出现死胡同。若未来引入真实审核整改工作流，本决策需与一对一唯一约束一并重审。
