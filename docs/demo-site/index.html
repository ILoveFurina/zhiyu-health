WSS 实时对话

📅
对话内挂号
C 端无直连挂号端点，经 Agent 工具回调 POST /api/agent/appointments，防超卖与幂等由 server-java 保障。
📄
报告两阶段上传
逐文件 POST /report-interpretation-uploads，全部完成后 POST /finalize 合并解读，request_id 幂等。
👤

SAFETY · 医疗安全边界

确定性规则 + 免责声明全覆盖

红线症状与用药禁忌由 server-java 确定性规则判断，LLM 只负责表达；所有 AI 产出携带免责声明。

🚨
红线症状中断
胸痛伴冷汗、意识模糊、呼吸困难等规则组合命中时，立即中断普通导诊，返回红色警告与 120 建议，不调用推荐/挂号工具。
💊
用药禁忌拦截
过敏史 + 候选药品 + Neo4j 知识，确定性规则给出 SAFE/BLOCKED/REVIEW_REQUIRED；医生开方、处方审核、患者查药复用同一规则。
⚠
免责声明兜底
server-py 生成时注入，server-java 在所有 AI 响应出口和持久化前校验补齐，固定文案来自 contracts/disclaimer.json。
🔒
号源防超卖
Redis 原子 DECR 预扣 + PostgreSQL 事务写入 + 失败精确补偿；唯一约束防重复预约，并发抢最后 1 个号源恰好 1 个成功。
⚠ 紧急提醒
您描述的"胸痛伴冷汗"属于紧急症状，请立即拨打 120 或前往最近急诊，不要等待在线导诊。
命中红线规则时由 server-java 直接产出 red_flag 事件，不进入 Agent

SUMMARY

项目亮点总结

🏗️
清晰的职责边界
server-java 唯一入口与业务写入方，server-py 只编排 Agent 与只读检索；8 份跨栈契约 JSON 作为单一事实源，双栈契约测试钉死。
🛡️
医疗安全优先
红线规则先于 LLM，用药禁忌确定性判断，免责声明全覆盖；号源 Redis 原子扣减 + PG 事务对账防超卖。
🔗
B+C 真实联动
C 端挂号产生的挂号单与病情摘要直接进入 B 端接诊台；处方审核结果同步医生与患者，双端读取同一业务记录。
📊
可观测可演示
WSS 多跳链路留痕"流走到哪、在哪断"；Agent trace 只记脱敏摘要；演示重置三重保护；并发抢号脚本现场证明防超卖。
