# 阶段三技术栈约束

## 名词解释

B  端：面向企业或内部员工使用的产品。通常关注效率、数据管理、权限。

C  端：面向普通消费者使用的产品。通常关注易用性、视觉体验和用户增长。

## B  端技术栈约束

技术栈：  React  +  TypeScript（不使用  Vue）

应用框架：Umi、Vite

请求库：umi自带的请求request，Tanstack  Query，axios

组件库与可视化图表库：antd  Design、antv

工具库：lodash、dayjs、moment、aHooks

路由库：React  Router；Umi  自带的路由体系

状态管理库：Zustand

样式方案：css，less

## C  端技术栈约束

#### H5  应用

技术栈：React  +  TypeScript（不使用  Vue）

应用框架：  Umi、Vite   请求与数据管理：  Umi自带的请求request，Tanstack  Query，axios

组件库：Ant  Design  Mobile

可视化：AntV  F2

路由：  React  Router；Umi  自带的路由体系

状态管理：Zustand

工具库：Lodash、Day.js、aHooks

样式方案：  CSS、Less、  CSS  Modules

其他：

1.  熟悉移动端适配、响应式布局及  H5  兼容性处理，不用内嵌到  app  和  支付宝小程序
