# 项目结构

### B端 和 H5 项目结构

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/meonar5Z2byJrqXx/img/9c3edce5-1d08-4976-90c7-7eed1e1db1ee.png)

#### 顶层目录结构

```typescript
migrate-Children/
├── config/                 # 配置文件
│   ├── config.ts           # Bigfish 运行时配置
│   └── routes.ts           # 路由配置
├── mock/                   # Mock 数据
│   └── afs2demo/           # 示例 Mock 接口
├── public/                 # 静态资源
├── src/                    # 主要源码
├── test/                   # 测试文件
├── docs/                   # 文档目录
├── .husky/                 # Git Hooks（commit-msg, pre-commit）
├── .vscode/                # VS Code 配置
├── .claude/                # ai 规范配置
├── CLAUDE.md               # 指令文件
├── package.json
├── tsconfig.json
├── .eslintrc.js
├── .prettierrc.js
├── .stylelintrc.js
├── .editorconfig
└── README.md

```

#### src 顶层结构

```typescript
src/
├── access.ts               # 权限控制配置
├── app.tsx                 # 应用入口（运行时配置）
├── type.d.ts               # 全局类型声明
├── overrides.css            # 全局样式覆盖
├── assets/                  # 静态资源
├── components/              # 公共组件
├── constants/               # 全局常量定义
├── hooks/                   # 自定义 Hooks
├── icons/                   # SVG 图标
├── layouts/                 # 布局组件
├── models/                  # 数据模型（全局状态管理）
├── pages/                   # 页面模块
├── services/                # API 服务层
├── typings/                 # 类型定义文件
└── utils/                   # 工具函数

```

### 小程序项目结构

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/meonar5Z2byJrqXx/img/af39d975-d6eb-42a7-83a1-45b9bba5215b.png)

```typescript
project/
     ├── app.js / app.json / app.acss     # 入口与全局配置
     ├── mini.project.json                # 项目配置
     ├── package.json
     │
     ├── pages/                           # 页面（按功能模块拆分）
     │   └── [module]/
     │       ├── index.js                 # 页面逻辑
     │       ├── index.axml               # 页面结构
     │       ├── index.acss               # 页面样式
     │       └── index.json               # 页面配置
     │
     ├── components/                      # 公共组件
     │   └── [component]/
     │       ├── index.js
     │       ├── index.axml
     │       ├── index.acss
     │       └── index.json
     │
     ├── services/                        # 接口服务层（API 请求封装）
     │   └── api.js
     │
     ├── utils/                           # 工具函数
     │   ├── util.js
     │   └── constants.js
     │
     ├── store/                           # 全局状态管理
     │   └── index.js
     │
     ├── styles/                          # 全局样式变量与混入
     │   └── variables.acss
     │
     ├── images/                          # 静态图片资源
     │
     └── docs/                            # 项目文档

```
