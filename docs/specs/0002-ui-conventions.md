# UI 约定（Spec 0002）

前端一切样式与命名的唯一标准。施工任何前端相关票（C 端小程序、B 端后台）前必读。
来源：原型最终版（`.scratch/zhiyu-mvp/prototype/chat-page.html`，已验收，可作施工期视觉参照）。

## 色板（已定稿）

- 品牌主色（青绿，已拍板）：`#0e8a7d`；渐变 `#0e8a7d → #12b8a5`（问候区/头部装饰/吉祥物）
- 页面背景：薄雾青绿垂直渐变 `#e9f6f2 → #f4faf8 → #f8faf9`；导航栏透明悬浮于背景之上，不加白底白条
- 用户气泡：`#95deae`；AI 气泡与一切卡片：白 `#fff`
- 状态色（**不随品牌主色变化，永远固定**）：危险红 `#e64545`（红线症状全屏警告）；情绪暖橙 `#fff8f0` / `#ffd591` / `#b25f00`（焦虑态气泡、边框与标签）
- 中性：次要文字 `#999`，输入框底 `#f2f3f5`，免责声明细条底 `#f5f5f5`
- B 端不定制主题，用 Ant Design 默认色（赛题硬约束：React + Umi + AntD，禁用 Vue）

## C 端聊天页（演示主画面）

- **导航栏**：`‹` 返回 + `☰` 对话记录抽屉 + 产品名"智愈"**左对齐**，图标与标题间距约 14px，**透明悬浮**于页面背景之上（不加白底）
- **☰ 抽屉**（票 27）：左侧滑出、宽约 78%、半透明遮罩，两段结构。顶部"我的"区三行业务入口——健康档案（故事 42/15，票 21）、我的挂号（故事 8，票 07）、用药提醒（票 22），文字行 + ›，通往对应页面；下方"对话记录"区——"对话记录 + ＋新对话"标题行，列表按最近活跃倒序、**不做时间分组**、单条删除。除上述四项外不加任何入口（不做个人中心/设置/任务中心/智能体市场）
- **空状态**：吉祥物插画位（润色阶段 AI 生成 3D 形象）+ 问候语（助手自称"小愈"）+ 推荐提示词，提示词用**话题卡**样式（# 图标 + 竖排白卡 + 右侧箭头，参考蚂蚁阿福），不用 chips
- **功能入口**：横排可滑动胶囊，固定在输入栏上方（AI诊室/拍皮肤/拍药盒/找医院/看报告/拍饮食），图标用 antd-mini icon
- **输入栏**（双行结构，参考腾讯健康）：
  - 行 1：输入框，placeholder 统一写"发消息或按住说话…"；点语音键切换为"按住 说话"长条（`my.getRecorderManager` 录音 → 火山引擎语音识别，票 20）
  - 行 2：`[🎤语音] [当前档位 ▸] [咨询人 ▸] …… [发送]`；档位胶囊循环 自动/快速回答/深度思考，主色描边；咨询人胶囊切换本人及家人档案（票 21）
- **引导卡片**：白卡、圆角 12px、轻阴影；标题行 = 图标 + 功能名；操作按钮主色填充/描边各一；底部 hint 小字 `#999`。找医院卡含定位按钮，拍照类卡含拍照/上传按钮
- **AI 诊室步骤条**：引导卡内一行文本进度，形如 `01·描述症状 » 02·科室推荐 » 03·完成挂号`，当前段主色高亮（参考蚂蚁阿福，成本一行字，必须做）
- **咨询人上下文条**：进入 AI 诊室/导诊流程后，流程卡顶部一行"本次咨询人：本人 | 切换"；档案姓名在展示时脱敏（如"本\*人"，参考蚂蚁阿福）

## 免责声明（硬约束，样式不得漂移）

- 文案固定："仅供参考，不替代医生诊断"，一字不改
- **双保险**：① 每条 AI 医疗建议气泡内嵌——10px `#999`，顶部 1px 虚线分隔；② 输入栏上方常驻细条，灰底 `#f5f5f5` 居中
- B 端（病情摘要、就诊小结、处方安全提醒等一切 AI 产出）用 AntD Alert 组件，同款文案
- 结构消息卡片（挂号卡/处方卡/报告解读卡等）底部一律内嵌该声明

## 情绪与红线

- 焦虑态：医疗建议气泡转暖橙底 + 橙边框 + "情绪感知：焦虑"标签 chip，安抚文案由 system prompt 负责（样式只管变色）
- 红线症状：全屏红色警告（底 `#e64545` 白字），中断当前流程，文案含"尽快就医/拨打 120"；不得用普通卡片样式呈现

## B 端后台

- Ant Design 默认主题 + 官网示例结构（表格页/表单页），不自定义视觉
- 医生工作台、接诊台等功能页以信息密度优先，不做"高级感"润色

## 命名

- 产品名"智愈"：标题栏、登录页等一切正式位置；助手人设名"小愈"：气泡自称、欢迎语（见 `CONTEXT.md`）

## 润色阶段（票 25 前后，约 1 天）

- AI 生成 3D 吉祥物（小愈形象）与欢迎卡插画，填入空状态预留位
- 渐变背景、字重/阴影微调；只动 C 端聊天页与健康管理页两个演示主画面
