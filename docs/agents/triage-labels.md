# Triage Labels

工程技能使用五种规范 triage 角色。下表将角色映射到本仓库本地 Markdown 票单使用的状态字符串。

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该问题 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分说明，可由 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个 triage 角色时，使用表中对应的本地状态字符串。需要适配其他词汇时，可直接修改右侧映射列。
