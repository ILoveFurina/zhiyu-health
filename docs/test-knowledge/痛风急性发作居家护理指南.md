# 痛风急性发作居家护理指南

痛风是嘌呤代谢紊乱导致血尿酸升高、尿酸盐结晶沉积于关节而引发的炎症性疾病。急性发作常见于足部第一跖趾关节，表现为夜间突发的剧烈疼痛、红肿、皮温升高，触碰即痛。

## 急性期处理要点

发作期以镇痛和休息为主。建议卧床并抬高患肢，减少负重与活动。可用冰袋局部冷敷每次 15-20 分钟，每日数次，以减轻红肿与疼痛，避免热敷以免加重炎症。

## 饮食与生活方式调整

应严格限制高嘌呤食物摄入，包括动物内脏、浓肉汤、海鲜尤其是贝类和沙丁鱼、啤酒等。多饮水，每日 2000 毫升以上，促进尿酸排泄。急性期避免剧烈运动，待症状缓解后再逐步恢复锻炼。

## 何时就医

若疼痛持续不缓解、伴发热、或关节红肿明显加重，建议尽快到风湿免疫科或骨科就诊。长期反复发作、出现关节畸形或皮下痛风石者，需在医生指导下进行降尿酸治疗。

## 就医建议科室

反复发作的痛风、需评估是否启动降尿酸治疗者，建议到风湿免疫科；关节局部严重红肿热痛、怀疑合并感染或需关节抽液减压者，可到骨科评估。
